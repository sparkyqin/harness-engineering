# 换号登录强制覆盖访客语言导致 UI 串语言

## 类型
pitfall

## 问题场景
同一会话内 A 用户（john）把界面切到英文后登出，B 用户（jane，账户语言偏好 zh）登录，
登录成功瞬间 Header 语言回到中文——因为登录逻辑用 `res.uiLanguage || 'zh'` 覆盖了当前界面语言。

## 根因
登录成功回调把"账户语言偏好"当成"当前应显示语言"直接覆盖，忽略了"保留当前界面语言"的语义。
需求 R-012（换号登录保留当前界面语言）未在登录链路实现。

## 解决方案
换号登录（同会话内登出再登录）时，**不覆盖**当前界面语言：
- 登录成功若检测到已有本地界面语言 → 保留之，仅更新账户偏好到 profile。
- 仅在"首次登录（无本地语言）"时才用账户语言初始化。
- TE 须有 B 类 E2E：john 英文登出 → jane 登录 → Header 保持英文（对应 S-023）。
